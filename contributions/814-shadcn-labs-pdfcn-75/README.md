## 问题理解
The issue asks for a Timeline component in the registry. It has a vertical accent spine with dot markers. Each item shows a date (muted, fixed width), a title (semibold) and an optional body (muted). Acceptance criteria:
- spine and dots stay aligned across items of different heights
- splitting across pages leaves no orphaned markers
- TypeScript props
- a takumi implementation; forme can be a follow-up, but this patch does both
- docs with a live preview and a registry.json entry

## 合理性判断
- The maintainer opened it as `good first issue` / `help wanted` with a clear spec, and it adds a new component without changing existing behaviour.
- I followed the `key-value` component exactly: one file per base, the theme-provider, `resolveColor`, `StyleSheet.create`, docs mdx, the examples index and the registry.json entry shape.
- I did not add the `renderingBase` prop from the issue. In this repo the base is chosen by the registry entry path, and no component has that prop. The PR body explains this.

## 改动 (13 files, +776)
- `apps/web/registry/bases/{takumi,forme}/components/timeline/timeline.tsx`
  - `TimelineProps` (`items`, `accentColor="primary"`, `dateWidth=72`, `style`) and `TimelineItem`.
  - Each item is a `wrap={false}` row: [date column] [rail: top spine segment + dot + bottom spine segment (flexGrow)] [title/body].
  - The first item's top segment has no colour and the last item has no bottom segment, so the spine starts at the first dot and ends at the last.
  - The dot and the date are centred on the first line of the title, computed from the theme's body fontSize × lineHeight.
  - The only forme difference: the container is `width: "100%"`, matching forme key-value.
- `apps/web/examples/{takumi,forme}/timeline.tsx`: the demo is a 4-step project timeline.
- `apps/web/content/docs/components/{takumi,forme}/timeline.mdx`: copied from key-value.mdx, with Usage and an API table.
- `meta.json` ×2, `examples/__index__.ts` (imports and map entries), `registry.json` ×2: all inserted in alphabetical order (between `text` and `watermark`).
- `apps/web/public/r/{takumi,forme}/timeline.json` and `public/r/registry.json`: generated by `pnpm registry:build`.
